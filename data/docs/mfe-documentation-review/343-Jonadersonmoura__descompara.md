## Observations

**1. README.md:3.** Opening sentence says project consists of micro-frontends and names technology through package. Previous reviews record four applications (shell/three remotes), three active host → remote relationships and configured `@angular-architects/native-federation` (package.json:58). "Module Federation nativo" (English translation: "native Module Federation") accompanies exact package name recorded by dependency review, so was not treated as another technology. Line 31 sentence saying only "Module Federation" is claim 7. Sentence has two equally corroborated themes; Theme follows first property, `structure`.

**2. README.md:5.** Three environments are applications `marAberto`, `intranet` and `admin`, each with own entry, build and dev-server. All import `@descompara/shared-ui` components (admin/src/app/home/home.ts:7; intranet/src/app/home/home.ts:8; marAberto/src/app/home/home.ts:8; also login screens, e.g. admin/src/app/login/login.ts:3), confirming reuse by multiple units. Repetitions: environment table (README.md:7-11), library tree description (README.md:25). Shell does not use `shared-ui`, but sentence concerns three environments.

**3. README.md:13.** Shell is host: loads manifest before bootstrap (shell/src/main.ts:3-5), manifest associates three names with `remoteEntry.json` URLs (shell/public/federation.manifest.json:2-4). Route table mounts `marAberto` at root, `intranet` at `intranet` and `admin` at `admin` (shell/src/app/app.routes.ts:4-20), constituting "orquestração da navegação" (English translation: "navigation orchestration"). "nenhum dos apps precisa saber dos outros em build-time" (English translation: "no app needs build-time knowledge of others") matches: shell configuration declares no remotes (shell/federation.config.mjs:3-18), and remotes import nothing from each other. Remote names appear in shell only as text passed to `loadRemoteModule`, URLs remaining in manifest included as build asset (shell/project.json:74-79). Repetitions: tree host/remote roles (README.md:19-22), second part of README.md:66 ("o shell descobre as URLs deles pelo manifesto", English translation: "shell discovers their URLs through manifest").
