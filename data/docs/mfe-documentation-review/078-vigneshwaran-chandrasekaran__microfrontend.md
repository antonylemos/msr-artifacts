# 078 — vigneshwaran-chandrasekaran/microfrontend

## Leitura do repositório

A documentação é o README da raiz, em inglês, o único arquivo `documentation` do `artifacts.csv`. É um tutorial longo: apresenta o projeto como exemplo de arquitetura de micro-frontends com Module Federation do webpack 5 (README.md:5-8), explica o conceito, conta passo a passo como as aplicações foram montadas, mostra a árvore de pastas, as responsabilidades do host, o fluxo de carregamento de um remote, as rotas, as portas, como rodar, como acrescentar uma página (iframe, remote React/Vue, remote Angular), os arquivos a estudar, a publicação na Vercel e problemas comuns. Os seis `package.json` têm `description`, e quase todos os arquivos de configuração e de entrada têm comentários explicativos; os componentes de cada remote exibem na tela um texto sobre a própria unidade.

No que diz da composição, o README confere com as revisões anteriores: um host React e quatro remotes (dois React, um Vue, um Angular) ligados por Module Federation, cada remote expondo um `./mount` que recebe um elemento do host, mais duas aplicações externas exibidas em iframe. As divergências são de detalhe e de publicação. A contagem de "five child apps" não bate com os seis destinos do host (afirmação 4); o README diz que todos os remotes usam `publicPath: 'auto'`, mas o Angular fixa `/angular-mfe/` em produção (afirmação 28); e o README descreve só a publicação conjunta num projeto Vercel, enquanto o snapshot também tem um `vercel.json` por diretório e a revisão de build e deploy deixou o deploy das cinco aplicações `Undetermined` (3.4.6, Leitura; afirmação 25). O comentário do cabeçalho de host/webpack.config.js:8-14 descreve ainda um terceiro arranjo, por variáveis de ambiente, que o código não usa (afirmação 29).
