# 078 — vigneshwaran-chandrasekaran/microfrontend

## Repository overview

Documentation is root README, in English, the only `documentation` file in `artifacts.csv`. A long tutorial: it presents a micro-frontends architecture example with webpack 5 Module Federation (README.md:5-8), explains the concept, recounts step-by-step application setup, and shows folder tree, host responsibilities, remote loading flow, routes, ports, running instructions, adding a page (iframe, React/Vue remote, Angular remote), files to study, Vercel publishing and common issues. All six `package.json` files have `description`, and almost all configuration and entry point files have explanatory comments; each remote's components display text about the unit itself.

On composition, README matches previous reviews: a React host and four remotes (two React, one Vue, one Angular) connected through Module Federation, each exposing `./mount` receiving a host element, plus two external applications displayed in iframes.
