# 084 — pmiguras/likekiri-website

## Repository overview

Documentation is extensive and entirely in Spanish. Its center is `README.md` (361 lines), accompanied by agent-oriented `CLAUDE.md`, nine ADRs in `docs/adr/`, a module integration guide (`docs/como-integrar-un-modulo.md`), a design system proposal (`docs/design/design-system.md`) and a README per module. Texts describe the platform as a "microkernel híbrido" (English translation: "hybrid microkernel"): a NestJS core knowing no business domain, independent modules publishing a signed manifest and federated bundle, and two surfaces, public site `likekiri.com` (React shell with SSR and islands) and dashboard `admin.likekiri.com` (SPA whose menu and pages come from manifests) (CLAUDE.md:3-5; README.md:3-9). This matches previous reviews: two React/Vite shells and ten `@module-federation/vite` remotes (3.4.2; 3.4.3), runtime-only composition without static `remotes`, with core resolving routes (3.4.4; 3.4.5 Overview), own build for twelve applications and separate module deployments, while both shells run in core's process (3.4.6). Documentation goes beyond previous reviews in flow detail (registry, delegated SSR, widgets) and generally matches code. Differences lie in texts left behind when delegated SSR was introduced (rows 42, 54 and 63), README diagram (rows 14 and 15), request flow forgetting Caddy-served `/assets/*` (row 17), `hello` admin static origin (row 44) and site's "estático" header (English translation: "static") (row 62).

## Observations

**1. CLAUDE.md:3-5.** The sentence summarizes the platform, with an artifact for each part. Core is NestJS backend judged `No` as a frontend unit by section 3.4.3 (row apps/core). "Independientes" (English translation: "Independent") here means own processes, builds and deployments (3.4.6 #3-#12).

**2. CLAUDE.md:10-11.** `grep -rn "modules/" apps/core/src` proposed by the text itself returns empty in snapshot, and core's `package.json` depends, among workspace packages, only on `@likekiri/contract` (apps/core/package.json:16).
