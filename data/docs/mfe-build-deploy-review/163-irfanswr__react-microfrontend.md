Each project has its own `package.json`, lockfile and build script. Both webpack projects use the same script pair generated by create-single-spa, `"build": "concurrently npm:build:*"` and `"build:webpack": "webpack --mode=production"` (parent-app/package.json:10-11; react-child-app/package.json:6-7), over configurations `webpack-config-single-spa` and `webpack-config-single-spa-react` (parent-app/webpack.config.js:7-13; react-child-app/webpack.config.js:5-11). No script triggers all three builds together.

No deployment artifact is present in snapshot: no Dockerfile, compose, CI workflow or hosting configuration, and `matches.csv` has no `ops-*`, `ci-*` or `cfg-public-path` occurrences. The only hooks are husky `pre-commit` hooks, running formatting, tests and lint (parent-app/.husky/pre-commit:4; react-child-app/.husky/pre-commit:4), without build or publication. The `parent-app` declares package `serve` as a development dependency (parent-app/package.json:32), but no script uses it.

Everything snapshot executes is for development: `webpack serve` on ports 9000 and 8081 and `vue-cli-service serve` on 8082 (parent-app/package.json:4; react-child-app/package.json:4; vue-child-app/package.json:6).
