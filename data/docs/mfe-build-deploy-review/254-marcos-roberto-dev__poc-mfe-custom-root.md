single-spa proof of concept with Vue 3 in four independent projects, without root `package.json` or workspace. Each project has its own `package.json`, lockfile and build configuration. Each build writes to its own project `dist/`, excluded by `.gitignore` files (content-app/.gitignore:11; root-app/.gitignore:11; root-classic/.gitignore:62; topbar-app/.gitignore:11).

No deployment artifact is present in snapshot. The `matches.csv` has no `ops-*`, `ci-*` or `cfg-public-path` occurrence, and no Dockerfile, compose, CI workflow, deployment manifest or hosting configuration exists. The `serve` is in `devDependencies` of `root-classic` (root-classic/package.json:31), but no script uses it.

All snapshot addresses are for development. Both hosts’ import maps point remotes to source code served by Vite dev server, `http://127.0.0.1:5174/src/main.ts` and `http://127.0.0.1:5175/src/main.ts` (root-app/index.html:14-15; root-classic/src/index.ejs:34-35). The `topbar-app` is the only remote with build prepared for loading by a host: output `app.js` in SystemJS format (topbar-app/vite.config.ts:8-18). The `root-app/src/importMap.json:3-4` and `root-app/mfe-app.json:3-4` contain other local URLs (`/spa.js`, port 5173), but no snapshot file reads them, as already recorded in composition review.
