# 283 — israelmeinert/fiap-aula-arquitetura-no-front

## Leitura do repositório

Material de aula com 14 blocos de exemplos num único workspace npm (`package.json:9-15`) e num único `angular.json` com 13 projetos Angular. Todo o build é local: o `npm run build` da raiz roda `scripts/build.mjs`, que lista os workspaces, filtra por número e framework se pedido, e executa o `build` de cada um em sequência (`package.json:23`; `scripts/build.mjs:6-11`). Cada aplicação gera o próprio artefato: `dist/` do Vite nas React e no shell, `dist/` de cada projeto no `angular.json` (ex.: `angular.json:21`), `.next/` no Next e `dist/` no Astro. O `.gitignore` ignora esses diretórios de saída (`.gitignore:2-5`).

Não há nenhum artefato de deploy no snapshot: nem Dockerfile, nem compose, nem CI, nem configuração de hospedagem ou proxy. A mineração não registrou nenhuma ocorrência `ops-*`, `ci-*` ou `cfg-public-path` para este repositório. Tudo o que serve as aplicações é de desenvolvimento e escuta em `127.0.0.1`: o `npm run aula -- N framework` sobe o `dev` do exemplo escolhido e, quando preciso, a API didática em 4010 (`scripts/aula.mjs:17-35`; `mocks/server.mjs:39`). Por isso as React usam todas a porta 5173, as Angular a 4200 e as Next a 3000: um exemplo roda por vez. O teste e2e usa o mesmo `npm run aula` para subir os exemplos (`tests/e2e/aula.spec.ts:12`, `:143`). Os `next start` dos dois Next e o servidor SSR do `11-angular` servem builds de produção, mas são executados à mão, sem artefato que os empacote ou publique (ver as Observações 23, 27 e 22).

No bloco 10, os dois remotos têm build próprio pelo script comum `scripts/build-remoto.mjs`, que gera um `dist/microfrontend.js` ESM por remoto (`scripts/build-remoto.mjs:21-26`), e são servidos por `scripts/servir-remoto.mjs` nas portas 4301 e 4302, com CORS para o shell em 4300 (`scripts/servir-remoto.mjs:2-6`). Esse servidor é local e de laboratório. O README do bloco descreve um "caminho de publicação independente" e manda publicar cada `dist/` à parte e ajustar as URLs do manifesto, mas diz que "o laboratório não provisiona um pipeline de deploy" (`exemplos/10-micro-frontends/README.md:111`, `:125`). Isso é documentação, não artefato; não decide a coluna Deploy. O BFF `exemplos/13-bff/apps/web-bff` (Express em 4011, `exemplos/13-bff/apps/web-bff/src/main.ts:5`) e a API didática `mocks/server.mjs` são servidores de apoio, sem build de produção nem deploy.
