# 283 — israelmeinert/fiap-aula-arquitetura-no-front

## Repository overview

Class material with 14 example blocks in a single npm workspace (`package.json:9-15`) and a single `angular.json` with 13 Angular projects. All builds are local: root `npm run build` runs `scripts/build.mjs`, listing workspaces, filtering by number and framework if requested, and executing each `build` sequentially (`package.json:23`; `scripts/build.mjs:6-11`). Each application generates its own artifact: Vite `dist/` for React applications and shell, each project’s `dist/` in `angular.json` (e.g.: `angular.json:21`), `.next/` for Next and `dist/` for Astro. The `.gitignore` ignores these output directories (`.gitignore:2-5`).

No deployment artifact is present in snapshot: no Dockerfile, compose, CI, hosting configuration or proxy. Mining recorded no `ops-*`, `ci-*` or `cfg-public-path` occurrence for this repository. Everything serving applications is for development and listens at `127.0.0.1`: `npm run aula -- N framework` starts selected example’s `dev` and, when needed, teaching API on 4010 (`scripts/aula.mjs:17-35`; `mocks/server.mjs:39`). Thus React applications all use port 5173, Angular applications 4200 and Next applications 3000: one example runs at a time. The e2e test uses same `npm run aula` to start examples (`tests/e2e/aula.spec.ts:12`, `:143`). Both Next applications’ `next start` and SSR server of `11-angular` serve production builds, but run manually without any artifact packaging or publishing them (see Observations 23, 27 and 22).

In block 10, both remotes have their own build through shared script `scripts/build-remoto.mjs`, generating one ESM `dist/microfrontend.js` per remote (`scripts/build-remoto.mjs:21-26`), and are served by `scripts/servir-remoto.mjs` on ports 4301 and 4302, with CORS for shell on 4300 (`scripts/servir-remoto.mjs:2-6`). This is a local laboratory server. Block README describes a "caminho de publicação independente" (English translation: "independent publication path") and instructs publishing each `dist/` separately and adjusting manifest URLs, but states "o laboratório não provisiona um pipeline de deploy" (English translation: "the laboratory does not provision a deployment pipeline") (`exemplos/10-micro-frontends/README.md:111`, `:125`). This is documentation, not an artifact; it does not decide Deploy column. BFF `exemplos/13-bff/apps/web-bff` (Express on 4011, `exemplos/13-bff/apps/web-bff/src/main.ts:5`) and teaching API `mocks/server.mjs` are supporting servers without production build or deploy.
