- **RQ1 (sinais enganosos):** listas geradas de estrelas (“awesome-stars” via `starred`) contêm nomes e descrições de qualquer repositório marcado pelo titular. Uma única estrela num repositório de micro-frontends basta para os hits terminológicos e de tecnologia.

O tamanho registrado difere entre as rodadas (8501 × 2867), e a versão indexada não está no clone parcial, então a linha casada nas buscas não é verificável localmente. O hit plural `microfrontends` não tem grafia literal no README do SHA. Sugere um filtro automático para repositórios cujos commits são quase todos de bot de listas geradas.
