# 309 — tonoizer/react-mf-patch-skew-repro

## Context

Minimal reproduction of a `@module-federation/vite` 1.21.6 defect (`README.md:1–5`). Production builds of federated Vite apps fail when React is shared as a singleton (`requiredVersion: '^19.2.4'`) and each app installs a different React 19.2.x patch. Repository sets up a pnpm monorepo with four React + Vite applications for this:
- `host`, consuming `remote_a` and `remote_b`;
- `remote_a`, exposing `./App` and acting as nested host for `remote_c`;
- `remote_b` and `remote_c`, exposing `./App`.
